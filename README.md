# CodeAlpha Cyber Security Tasks

This repository groups the task submission materials into separate folders.

## Tasks included

1. **Task 1 — Basic Network Sniffer**
2. **Task 2 — Phishing Awareness Training**
3. **Task 3 — Secure Coding Review**
4. **Task 4 — Network Intrusion Detection System (NIDS)**

## Important testing notes

- Review each task's README and checklist before submitting.
- Task 1 requires testing packet capture on your own machine/network with the required permissions and capture driver.
- Task 2 is an educational phishing-awareness module, not a live phishing detector.
- Task 3 includes an educational pattern checker and a deliberately vulnerable training sample. Verify findings and document actual tests; do not use the sample in production.
- Task 4 includes a dashboard/demo and example Suricata configuration materials. The dashboard's demo alerts are synthetic; the real NIDS requirement still needs Suricata configured and tested in an authorized lab.
- Do not claim a feature was tested unless you personally tested it and can provide evidence.
- Never upload passwords, API keys, private data, or other secrets.

## Suggested GitHub upload steps

1. Create a GitHub repository named `codealpha_tasks`.
2. Extract this ZIP file on your computer.
3. Open the extracted `codealpha_tasks` folder.
4. Upload the files and folders inside it to the GitHub repository (not the outer ZIP file).
5. Check that the README and all four task folders appear on GitHub.
6. Copy the repository URL into the relevant submission-form GitHub fields.

## Suggested submission

The October batch form says to complete any 2 or 3 tasks. Choose the tasks you have actually tested and can explain. Confirm the exact requirements in your current form and offer letter.
