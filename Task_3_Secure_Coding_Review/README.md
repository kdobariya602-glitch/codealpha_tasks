# CodeAlpha Task 3 — Secure Coding Review

## Start here
Watch `Task_3_Simple_English_Tutorial.mp4` first.

## Run CodeLens
1. Install Python 3.10 or newer.
2. Double-click `RUN_WEBSITE_WINDOWS.bat`.
3. Open `http://127.0.0.1:5003`.
4. Click Start Review, then Use Built-in Sample.
5. Read findings, explanations, safer patterns, and download the report.

## Included review target
`audit_sample/intentionally_vulnerable_training_sample.py` is deliberately insecure training code. It is included so you have a concrete source file to review. Do not deploy it.

## Important
CodeLens is an educational pattern checker, not a complete security scanner. The accompanying report documents findings in the included training sample, not in an unrelated production application. Complete the test record with your own actual run results.
