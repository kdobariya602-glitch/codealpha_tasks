# CodeAlpha Task 1 — Basic Network Sniffer

## Watch first
Open `Task_1_Simple_English_Tutorial.mp4`. It uses simple English narration and clear step-by-step text.

## Windows setup
1. Install Python 3.10+ and Npcap from https://npcap.com/.
2. Extract this ZIP and open this project folder.
3. Open Command Prompt in the folder.
4. Run `py -m pip install -r requirements.txt`.
5. Run `py app.py`.
6. Open `http://127.0.0.1:5001/`.

Sample data is simulated and is only for preview. Live capture depends on Npcap, permissions and a supported capture interface. Only monitor networks you own or are authorized to monitor.
