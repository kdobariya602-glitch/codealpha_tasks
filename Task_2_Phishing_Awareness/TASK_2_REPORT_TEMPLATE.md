# Task 2 — Phishing Awareness Training Report

## Objective
Teach users how to recognize phishing emails, fake websites, social engineering, and related scams.

## Project and technology
SecureWise phishing-awareness website using HTML, CSS, and vanilla JavaScript.

## Main learning features
- Phishing email and fake website examples
- Social engineering and safety guidance
- Video and official resource links
- Scenario-based assessment with feedback
- Browser-local progress and report/certificate features where supported
