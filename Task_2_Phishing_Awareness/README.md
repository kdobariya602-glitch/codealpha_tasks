# CodeAlpha Task 2 — Phishing Awareness Training

## Start here
Watch `Task_2_Simple_English_Tutorial.mp4` first.

## Run the website
1. Extract the ZIP.
2. Open `Task_2_Phishing_Awareness_Blue_Improved`.
3. Double-click `index.html` in Chrome or Edge.
4. Keep `index.html`, `styles.css`, and `script.js` together.
5. Explore the sections, use the video/resource links, and complete the final assessment.

## Evidence to capture
- Dashboard and learning sections
- Phishing email or fake website examples
- Quiz results and explanations
- Any local report/certificate feature you use

## Scope and limits
This is a browser-based awareness training project. It does not scan real inboxes, block phishing, send emails, or collect credentials. Remote videos and resources need internet access. Confirm all claims against your own run before reporting results.
